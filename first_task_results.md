# Результати тестування JSONPlaceholder API

## Мета
Перевірка коректності роботи GET, POST, PUT, PATCH, DELETE запитів 
до jsonplaceholder.typicode.com під навантаженням 100 користувачів, 
ramp-up 10 секунд, 3 ітерації.

## Результати
За даними View Results Tree та Summary Report усі запити (GET, POST, 
PUT, PATCH, DELETE) виконались успішно у всіх ітераціях, без помилок 
з’єднання чи таймаутів.

Для кожного запиту пройшли всі три встановлені assertion
(Response Code, Size, JSON Assertion): відхилень не виявлено.

## Висновок
API стабільно витримує задане навантаження, відповіді відповідають 
очікуваній структурі та статус-кодам. Критичних помилок під час 
тестування не зафіксовано.
